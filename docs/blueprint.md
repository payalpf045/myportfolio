# **App Name**: PhotoFlow

## Core Features:

- Image Upload: Upload photos through the admin panel, with support for large image sizes (up to 20MB).
- Image Deletion: Delete photos through the admin panel.
- Image Display: Display uploaded photos on the website in an appealing gallery format.
- Real-time Updates: Website gallery updates in real-time to reflect image uploads and deletions.
- Upload Progress Bar: Display a progress bar during image uploads to indicate the upload status to the user.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082), evoking a sense of professionalism and creativity.
- Background color: Very light lavender (#F0F8FF) for a clean, unobtrusive backdrop that allows the photographs to stand out.
- Accent color: Muted gold (#B8860B), used for interactive elements and highlights.
- Body text: 'PT Sans', a versatile sans-serif for readability. Headlines: 'Playfair', a high contrast serif for a modern, elegant feel.
- Simple, minimalist icons for navigation and actions within the admin panel.
- Clean, grid-based layout for the photo gallery to ensure a professional and organized display.
- Subtle fade-in animations for image loading and transitions in the gallery.
